C# TopBar Component

A modern and customizable TopBar (Title Bar) component built in C# for desktop applications.
This project is designed to replace or enhance the default window title bar, giving your application a cleaner and more flexible user interface.

✨ Features

Custom TopBar / Title Bar UI

Window controls (Minimize, Maximize, Close)

Draggable window support

Easy customization (colors, buttons, layout)

Lightweight and easy to integrate

Written entirely in C#
